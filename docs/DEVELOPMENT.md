# Разработка NIKA Desktop

[← README](../README.md) · [Бенчмарки](BENCHMARKS.md)

## Требования

- Mac с Apple Silicon и macOS 26+ для текущей сборки локального движка.
- Xcode 16.4+ со Swift 6, Python 3 и Homebrew.
- `llama.cpp`: `brew install llama.cpp`.
- Интернет для первого скачивания WebRTC и моделей. Загруженные локальные модели работают без сети.

Открой Xcode и заверши первоначальную настройку. Если активны только Command Line Tools:

```bash
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
```

Исходники SwiftUI объявляют macOS 14, но упаковываемый сейчас движок требует macOS 26.
Для старых macOS и Intel нужны совместимый движок и отдельная проверка.

## Запуск

```bash
git clone https://github.com/1nikitas/NIKA_desktop.git
cd NIKA_desktop
bash scripts/dev.sh
```

Скрипт собирает debug-приложение, добавляет движок, WebRTC, ресурсы и метаданные «Команд»,
создаёт локальную ad-hoc подпись и запускает приложение. Сертификат Apple для разработки
не нужен. Логи выводятся в Terminal; закрытие приложения — ⌘Q.

Локальная история dev-режима хранится в `.dev-data/`. Переменная `NIKA_DESKTOP_DATA`
меняет папку данных и отключает восстановление сохранённого входа, но не изолирует
полностью UserDefaults и Keychain. Для полностью отдельной среды используй другого
пользователя macOS. Ключи и сессии не должны попадать в репозиторий.

В приложении: **Локальные модели → NIKA Smart → скачать → Начать разговор**.
Для Smart на Mac с 8 ГБ используй контекст 4096, с проектором изображений — 2048.
Облачные возможности требуют входа через Telegram. Адрес сервера меняется на экране входа.
Серверная часть в этот репозиторий не входит.

## Работа в Xcode

```bash
open Package.swift
```

Выбери схему `NIKADesktop` и `My Mac`. Для проверки камеры, микрофона и системных
разрешений запускай упакованное приложение через `scripts/dev.sh`, затем подключайся
из Xcode: **Debug → Attach to Process → NIKADesktop**.

| Файл / каталог | Назначение |
| --- | --- |
| `Sources/NIKADesktop/NIKADesktopApp.swift` | Запуск, окна, меню и команды |
| `WorkspaceView.swift` | Навигация и разговор |
| `DesktopStore.swift` | Состояние аккаунта, окон и истории |
| `SettingsView.swift` | Настройки и вход через Telegram |
| `PersonalBots.swift` | Личные помощники и их редактор |
| `ModelLibrary.swift`, `LocalProvider.swift` | Загрузка моделей и локальное выполнение |
| `Shared/` | Общие модели данных, BFF-транспорт и парсеры |
| `Tests/NIKADesktopTests/` | Тесты интерфейса, данных и интеграций |

Короткие имена в таблице относятся к `Sources/NIKADesktop/`. Shared-файлы включены
как самостоятельные копии: соседний iPhone-репозиторий не требуется.

## Сборка

```bash
# Только компиляция
swift build --disable-sandbox

# Release-приложение с движком и ресурсами
bash scripts/build-app.sh
open 'build/NIKA Desktop.app'

# Упаковать debug-приложение без запуска
NIKA_BUILD_CONFIGURATION=debug bash scripts/build-app.sh
```

WebRTC закреплён на версии 154.0.0 в SwiftPM. Локальный движок берётся из установленного
`llama-server`. Подпись ad-hoc предназначена для разработки; нотариализованный установщик
в репозитории не поставляется.

## Проверки

```bash
CLANG_MODULE_CACHE_PATH=/tmp/nika-clang-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/tmp/nika-swift-cache \
swift test --disable-sandbox
```

Прогон 13.10.2026: 39 тестов пройдены, 5 интеграционных пропущены без внешних тестовых
данных, ошибок нет. Для интеграционных тестов можно задать:

| Переменная | Значение |
| --- | --- |
| `NIKA_TEST_GGUF` | Путь к Qwen3.5 0.8B Q8_0 |
| `NIKA_TEST_PROJECTOR` | Путь к подходящему проектору mmproj |
| `NIKA_TEST_DOWNLOAD_URL` | URL тестового HTTP-файла с содержимым `abc` |
| `NIKA_TEST_ARTIFACT_DIR` | Необязательная папка для сохранения тестового разговора |

HTTP-стенд запускается отдельной командой `python3 scripts/download-fixture.py`.
Его URL: `http://127.0.0.1:18283/model.gguf`, остановка — Ctrl-C.
Тесты бюджета памяти моделируют 8/16 ГБ, но не заменяют проверку на физическом Mac с 8 ГБ.
[Замер скорости 4B-модели](BENCHMARKS.md) проведён отдельно на M4 Pro с 24 ГБ.

После изменения чата проверь отправку, остановку, повтор, сохранение и повторное открытие
разговора. Для локального режима повтори вопрос без интернета. Для изменений интерфейса
проверь обе темы, узкое окно и многострочный ввод. Облако и голос требуют живого аккаунта
и соответствующих разрешений macOS.

## Устройство приложения

Каждое окно имеет свой `Workspace`; общие аккаунт, библиотека и история принадлежат
`DesktopStore`. Локальный `llama-server` работает отдельным процессом на 127.0.0.1
со случайным ключом доступа. Одновременно выполняется одна локальная генерация.

Модели скачиваются последовательно, с возобновлением и проверкой размера/SHA-256.
Локальная память отделена от памяти аккаунта. Ошибка локальной модели не переключает
запрос в облако; локальные действия требуют подтверждения. Смена режима начинает новый чат.

## Частые проблемы

- **`llama-server is required`**: установи llama.cpp и проверь `command -v llama-server`.
- **WebRTC не скачивается**: проверь доступ к GitHub и повтори `swift package resolve`.
- **SDK не найден**: проверь `xcode-select -p`, запусти Xcode и заверши его настройку.
- **Ошибка записи кэша**: используй временные каталоги из команды тестов выше.
- **Нет ресурсов или разрешений при запуске из Xcode**: используй упакованное приложение
  через `scripts/dev.sh` и подключи отладчик к запущенному процессу.
